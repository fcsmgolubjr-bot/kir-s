# Kir’s Studio

Персональный сайт независимого разработчика. GitHub Pages: https://fcsmgolubjr-bot.github.io/kir-s/

## Содержание

Главная: позиционирование → интерактивная витрина стилей → услуги → подход → автор → контакт.

Витрина содержит три работающие демонстрации, а не вымышленные клиентские проекты:

- FORMA (`styles/editorial.html`) — тёплый редакционный стиль; фильтрация визуальных исследований.
- VECTOR (`styles/industrial.html`) — строгий B2B; переключение уровней инженерной схемы.
- PULSE (`styles/product.html`) — цифровой продукт; режимы фокуса, рабочий локальный таймер, чек-лист.

Названия условные. Коммерческие результаты, отзывы, клиенты и награды не заявлены. Parkit в эту версию витрины не включён по просьбе владельца показывать пока стили, без кейсов.

## Запуск и публикация

Статический HTML/CSS/JavaScript без сборки, backend и секретов. Для локального просмотра:

```sh
python3 -m http.server 4174
```

GitHub Pages использует файлы корня ветки `main`. Все внутренние пути относительные и работают с префиксом `/kir-s/`. Никаких npm-зависимостей не требуется.

## Изменения и материалы

- Сохранены название, графитовая палитра, электрический лайм и реальные контакты: https://t.me/kgup3 и mailto:fcsmgolubjr@gmail.com.
- Переработаны композиция, типографика, структура и демонстрация визуального диапазона.
- Локальный шрифт Manrope, лицензия SIL Open Font License: `assets/OFL-Manrope.txt`. Основные тексты на Manrope; редакционные акценты используют системную Georgia.
- Вся графика нарисована в SVG/CSS для этих демо. Внешних фотографий, вымышленных моделей оборудования и тяжёлого WebGL нет.
- Превью отображают те же действующие HTML-страницы, которые открываются по ссылке. Формат телефона показывает реальную адаптивную вёрстку при ширине iframe 375 px.
- Контакты открывают Telegram/почтовый клиент; сайт сам не отправляет сообщения или заявки.

## Доступность и поведение

Семантические заголовки и навигация, видимый focus, клавиатурное управление вкладками, состояния aria-selected/aria-pressed, поддержка prefers-reduced-motion. Текст остаётся видимым при отключённом JavaScript; демо доступны по своим постоянным ссылкам. Первый редакционный стиль отображается по умолчанию.

## Проверка текущей версии

Проверены главная и три демо на ширинах 375 и 1280 px; главная дополнительно на 1440 px. Горизонтального переполнения и ошибок JavaScript не обнаружено. Проверены переключение стилей и формата превью, клавиатура, фильтр FORMA, уровни VECTOR, режимы PULSE, запуск/пауза и отсчёт таймера, чек-лист. Внутренние файловые ссылки проверены. Основные пары цветов текста проверены на контраст не ниже 4.5:1. OG-изображение — снимок главной страницы.
